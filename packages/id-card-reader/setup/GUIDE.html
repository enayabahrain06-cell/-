الخطوات

١

وصّل قارئ البطاقة

أي قارئ بطاقات ذكية USB قياسي (المجرَّب: ACS CCID USB Reader). يثبّت Windows التعريف تلقائيًا.

٢

ثبّت برنامج الهيئة GCC CardRead Server

شغّل المثبّت الموجود في مجلد iGA-installer. إن لم يكن موجودًا فاطلبه من هيئة المعلومات والحكومة الإلكترونية.

إذا كان البرنامج مثبّتًا مسبقًا على الجهاز فتجاوز هذه الخطوة.

٣

شغّل 1-Setup.cmd

  • ضع بطاقة هوية بحرينية في القارئ.
  • انقر مرتين على 1-Setup.cmd ووافق على نافذة Windows (نعم).
  • يجب أن ينتهي بالعبارة OK: the card was read with names.
٤

افتح النظام في Chrome أو Edge

عند الضغط على قراءة البطاقة لأول مرة قد يسأل المتصفح عن السماح للموقع بالوصول إلى الأجهزة على الشبكة المحلية. اختر السماح.

٥

تحقّق بـ 2-Check.cmd

مع وجود البطاقة في القارئ، يجب أن تظهر كل البنود بعلامة [OK].

العربية

ID card reader setup

For each PC that reads Bahrain ID cards (usually reception). Other PCs need nothing, and details can always be typed by hand.

What is in this folder

FilePurpose
1-Setup.cmdInstalls the Bahrain update into iGA's program (once, needs administrator approval).
2-Check.cmdChecks this PC and says what is missing. No rights needed.
3-Undo.cmdUndoes the update and puts the original files back.
iGA-installer\Put iGA's GCC CardRead Server installer here.
files\The updated Bahrain files and the setup scripts (don't edit).
NOTES.txtTechnical notes for IT.

Steps

1

Plug in the card reader

Any standard USB smart card reader (tested: ACS CCID USB Reader). Windows installs the driver by itself.

2

Install iGA's GCC CardRead Server

Run the installer in iGA-installer. If it isn't there, ask iGA (Information & eGovernment Authority) for it.

Skip this step if the program is already installed on the PC.

3

Run 1-Setup.cmd

  • Put a Bahrain ID card in the reader.
  • Double-click 1-Setup.cmd and approve the Windows prompt (Yes).
  • It should end with OK: the card was read with names.
4

Open the system in Chrome or Edge

The first time someone presses Read ID card, the browser may ask to let the site access devices on the local network. Choose Allow.

5

Confirm with 2-Check.cmd

With a card in the reader, every line should show [OK].

Troubleshooting

The page saysFix
The card reader program isn't runningStep 2: install iGA's program, or restart the PC.
No card / no readerStep 1: plug in the reader and insert the card fully.
