> **Approved changes applied (2026-09-27):** `packages.name_ar` / `name_en`; `registration_requests.waitlist_position`; new `refunds` table linked to the refund wallet transaction; `media` is the single source of truth for files, so the standalone path columns were **dropped** from `certificates`, `exam_attempts`, `exam_answers` and `payments` (only `students.photo_path` / `photo_thumb_path` remain as denormalised caches, because the students list and every roster render the thumbnail per row and a join to `media` on every list would cost more than the two cached strings). ## Portability notes per driver

| Concern | MySQL 8 | PostgreSQL 15 | SQLite |
|---------|---------|---------------|--------|
| Charset / collation | `utf8mb4` / `utf8mb4_unicode_ci`, `strict => true`, InnoDB | UTF-8 default | UTF-8 default |
| `time` columns | TIME | TIME | TEXT `HH:MM:SS`, compared as strings (zero-padded) |
| `boolean` | TINYINT(1) | BOOLEAN | INTEGER 0/1 |
| `text` JSON lists | TEXT | TEXT | TEXT |
| Foreign keys | native | native | `PRAGMA foreign_keys=ON` set in `config/database.php` |
| Concurrency | row locks | row locks | `journal_mode=WAL`, `busy_timeout=5000` |
| Date grouping in reports | done in PHP with Carbon after fetching `date` columns | same | same |
| Aggregates | COUNT/SUM/AVG/MIN/MAX only | same | same |
| Column change migrations | `doctrine/dbal` not needed on Laravel 11 native schema; SQLite rebuilds table automatically | native | native |
